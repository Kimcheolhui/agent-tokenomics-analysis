# 분석 설정

추출한 CSV와 함께 로컬 분석의 입력이 되는 값이다. 고객마다 채운다.

| 파일 | 내용 | 비고 |
| --- | --- | --- |
| `model-params.csv` | 모델별 단가와 캐시 파라미터 | 가이드 "모델별 캐시 파라미터" 표를 따른다. Model은 `calls.csv`의 `Model`(응답 모델명)과 정확히 같아야 한다 |
| `agents.csv` | 에이전트별 고정 Input 토큰 S_a | 가이드 3-B 측정법으로 구한다. A 범주 지표의 선행 입력이다 |

`Model` 값이 맞지 않으면 그 호출의 비용이 0으로 계산된다. `queries/views.sql`의 `unpriced_calls` 뷰로 매칭되지 않은 모델을 확인한다.

`agents.csv`를 채우지 않으면 A 공통 달성률, A1 미스율, A4 판정, B 공통 비중을 산출할 수 없다.
